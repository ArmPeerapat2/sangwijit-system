# E-learning

เฟส (ข้อเสนอ v0, รอยืนยัน): 4
สถานะ: ร่างโครง v0 ผู้ใช้จะแก้ทีหลัง **มีสเปกเดิมครบแล้ว** ที่ `Projects/Sangwijit-Academy` (Overview, TR Data Model, TR Core Flows, TR Screens 10 หน้า, TR Curriculum Map, TR Platform & Rollout) จึงไม่ควรออกแบบซ้ำ สิทธิ์ทุกปุ่มตั้งที่ตารางสิทธิ์ตำแหน่ง (`00_ระบบกลาง`)

## ขั้นตอนของระบบ

กำหนดคอร์สที่ต้องเรียนตามตำแหน่ง → พนักงานเปิดคลังคอร์สและเรียน → ทำแบบทดสอบ แสดงผ่าน/ไม่ผ่าน → ผ่านเกณฑ์ออกใบรับรองภายใน → รายงานผลต่อสาขา/ต่อคน

## หน้าและฟังก์ชัน

| รหัส | หน้า | ฟังก์ชันหลัก | เขต |
|---|---|---|---|
| EL-01 | คลังคอร์ส | ค้นหา/เปิดเรียนคอร์ส | เขียว |
| EL-02 | เส้นทางเรียนตามตำแหน่ง | กำหนดคอร์สที่ต้องเรียนต่อตำแหน่ง | เขียว |
| EL-03 | ทำแบบทดสอบ | ทำข้อสอบ แสดงผ่าน/ไม่ผ่าน | เขียว |
| EL-04 | จัดการคอร์สและข้อสอบ | อัปโหลดเนื้อหา (รวมคอร์สจาก Vendor) สร้างข้อสอบและเกณฑ์ผ่าน | เขียว |
| EL-05 | ใบรับรองภายใน | ออกใบรับรองเมื่อผ่านเกณฑ์ | เขียว |
| EL-06 | รายงานผลการเรียน | ผลต่อสาขา/ต่อคน | แดง (ถ้าผูก KPI/ค่าตอบแทน) |

## ค่าเริ่มต้นที่เสนอ

| เรื่อง | ค่า | สถานะ |
|---|---|---|
| เนื้อหาหลักสูตร | ใช้ WI 50 ฉบับที่มีอยู่ (1 WI = 1 หลักสูตรของตำแหน่ง) คลังข้อสอบอยู่ใน §8 ของ WI | มีอยู่แล้วตามสเปก Academy |
| เกณฑ์ผ่าน | ไม่เท่ากันทุกฉบับ อ่านจากไฟล์ ห้ามฮาร์ดโค้ด | ตามสเปก Academy |
| การจับคู่หน้า | เทียบ EL-01 ถึง EL-06 กับ TR Screens 10 หน้า | ข้อเสนอ ยังไม่ได้เปิดอ่าน TR Screens |
| ตำแหน่ง | ใช้รหัสตำแหน่งชุดเดียวกับ core | ตกลงแล้ว (G05) |
