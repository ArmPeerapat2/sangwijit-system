# งานคลัง

เฟส (ข้อเสนอ v0, รอยืนยัน): 3
สถานะ: ร่างโครง v0 ผู้ใช้จะแก้ทีหลัง ยังไม่ได้ grill สิทธิ์ทุกปุ่มตั้งที่ตารางสิทธิ์ตำแหน่ง (`00_ระบบกลาง`)

## ขั้นตอนของระบบ

รับสินค้าเทียบ PO (บันทึก serial/lot) → กำหนดตำแหน่งจัดเก็บ → เบิก-จ่าย/ใบส่งของ (ตรวจก่อนส่ง พิมพ์) → โอนย้ายระหว่างคลัง/สาขา (ส่ง-รับ ตรวจยอดรับ) → รับคืน/ของเสีย/ส่งคืนซัพพลายเออร์ (บันทึกสาเหตุ) → ตรวจนับ (เชื่อมกับสุ่มเช็คสต๊อก) → ตัวชี้วัดคลัง

## หน้าและฟังก์ชัน

| รหัส | หน้า | ฟังก์ชันหลัก | เขต |
|---|---|---|---|
| WH-01 | รับสินค้าเทียบ PO | ตรวจกับ PO บันทึก serial/lot แนบไฟล์ | แดง |
| WH-02 | ตำแหน่งจัดเก็บ | กำหนด/ดูตำแหน่งจัดเก็บ | เหลือง |
| WH-03 | เบิก-จ่าย/ใบส่งของ | ตรวจก่อนส่ง พิมพ์ใบส่งของ | แดง |
| WH-04 | โอนย้ายระหว่างคลัง/สาขา | ส่ง-รับโอน ตรวจยอดรับ | แดง |
| WH-05 | รับคืน/ของเสีย/ส่งคืน | บันทึกสาเหตุ ส่งคืนซัพพลายเออร์ แนบไฟล์ | แดง |
| WH-06 | ตรวจนับ | เชื่อมกับระบบสุ่มเช็คสต๊อก กรอกผลนับ ปิด | เหลือง |
| WH-07 | ตัวชี้วัดคลัง | เวลารับของ ความถูกต้องการจัดส่ง ของค้างคลัง | เหลือง |
