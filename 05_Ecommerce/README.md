# Ecommerce

เฟส (ข้อเสนอ v0, รอยืนยัน): 3
สถานะ: ร่างโครง v0 ผู้ใช้จะแก้ทีหลัง ยังไม่ได้ grill สิทธิ์ทุกปุ่มตั้งที่ตารางสิทธิ์ตำแหน่ง (`00_ระบบกลาง`)

## ขั้นตอนของระบบ

เลือกสินค้าที่แสดง/ซ่อน (ราคาและสต๊อกดึงจากข้อมูลหลัก) → ลูกค้าสั่งผ่านเว็บ → ออเดอร์ออนไลน์ → ตรวจการชำระเงิน (สลิปหรือผลจากเกตเวย์) ยืนยัน/ปฏิเสธ → เปิดบิลขายจากออเดอร์โดยไม่คีย์ซ้ำ กันบิลซ้ำต่อ 1 ออเดอร์ แท็กช่องทาง "ออนไลน์" → จัดส่งหรือรับที่สาขา ติดตามพัสดุ → คืน/เคลม อนุมัติหรือปฏิเสธ

## หน้าและฟังก์ชัน

| รหัส | หน้า | ฟังก์ชันหลัก | เขต |
|---|---|---|---|
| EC-01 | แคตตาล็อกออนไลน์ | เลือกสินค้าที่แสดง/ซ่อน ราคา/สต๊อกดึงจาก Master | แดง (ราคา) |
| EC-02 | ออเดอร์ออนไลน์ | กรองตามสถานะ ดูรายละเอียดออเดอร์ | เหลือง |
| EC-03 | ตรวจชำระเงิน | ตรวจสลิป/ผลจากเกตเวย์ ยืนยัน/ปฏิเสธ | แดง |
| EC-04 | เปิดบิลจากออเดอร์ | สร้างบิลขายจากออเดอร์ กันบิลซ้ำ แท็กช่องทางออนไลน์ | แดง |
| EC-05 | จัดส่ง/รับที่สาขา | เลือกวิธีรับ ติดตามพัสดุ เปลี่ยนสถานะ | เหลือง |
| EC-06 | คืน/เคลม | รับเรื่องคืน/เคลม อนุมัติ/ปฏิเสธ | แดง |
| EC-07 | สต๊อกออนไลน์ | ดูสต๊อกที่เปิดขายออนไลน์ | เหลือง |
