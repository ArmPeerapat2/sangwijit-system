# สุ่มเช็คสต๊อก

เฟส (ข้อเสนอ v0, รอยืนยัน): 3
สถานะ: ร่างโครง v0 ผู้ใช้จะแก้ทีหลัง ยังไม่ได้ grill สิทธิ์ทุกปุ่มตั้งที่ตารางสิทธิ์ตำแหน่ง (`00_ระบบกลาง`)

## ขั้นตอนของระบบ

ตั้งเกณฑ์การสุ่ม (ถ่วงน้ำหนักตามมูลค่า/ความผิดพลาดเดิม/สินค้าเคลื่อนไหวเร็ว) → สร้างใบงานนับ สุ่มรายการ ซ่อนจำนวนในระบบจากผู้นับ → ผู้นับกรอกจำนวนจริงและแนบรูป → เทียบจำนวนนับกับจำนวนในระบบ → สอบสวนสาเหตุของผลต่าง → อนุมัติผลปรับปรุง (เป็นเอกสารอนุมัติเพื่อนำไปปรับใน HERO) → สถิติความแม่นยำต่อสาขา/คลัง/คนนับ

## หน้าและฟังก์ชัน

| รหัส | หน้า | ฟังก์ชันหลัก | เขต |
|---|---|---|---|
| SC-01 | เกณฑ์การสุ่ม | ถ่วงน้ำหนักตามมูลค่า/ความผิดพลาดเดิม/สินค้าเคลื่อนไหวเร็ว | แดง |
| SC-02 | สร้างใบงานนับ | สุ่มรายการ ซ่อนจำนวนในระบบจากผู้นับ | เหลือง |
| SC-03 | หน้านับสต๊อก | ผู้นับกรอกจำนวนจริง แนบรูป (คอมก่อน มือถือทีหลัง) | เหลือง |
| SC-04 | เทียบผลต่าง | จำนวนนับเทียบจำนวนในระบบ ผลต่างต่อรายการ | เหลือง |
| SC-05 | สอบสวนสาเหตุ | บันทึกสาเหตุ/หลักฐาน ปิด | เหลือง |
| SC-06 | อนุมัติผลปรับปรุง | อนุมัติผลต่าง เพื่อนำไปปรับใน HERO | แดง |
| SC-07 | สถิติความแม่นยำ | ต่อสาขา/คลัง/คนนับ | เหลือง |

## ค่าเริ่มต้นที่เสนอ

| เรื่อง | ค่า | สถานะ |
|---|---|---|
| ซ่อนจำนวนในระบบจากผู้นับ | ใช่ | ตามชีต |
| ระบบใหม่ไม่เขียนกลับ HERO | SC-06 เป็นเอกสารอนุมัติเท่านั้น คนนำไปปรับใน HERO เอง | ข้อเสนอ ชีตระบุว่ารอยืนยัน |

## ข้อมูลที่ต้องการจากผู้ใช้

ยืนยันว่า SC-06 เป็นเอกสารอนุมัติเท่านั้น · ขนาดตัวอย่างและความถี่ของการสุ่ม · แหล่งจำนวนสต๊อกในระบบ (ชีต/HERO)

## สูตรที่รอ Formula Gate

เกณฑ์ถ่วงน้ำหนักการสุ่ม (SC-01) · ผลต่าง (SC-04) · ความแม่นยำ (SC-07)

## เชื่อมกับ

`13_คลัง` WH-06 ตรวจนับ · `00_ระบบกลาง` G08 ข้อมูลหลักสินค้า
