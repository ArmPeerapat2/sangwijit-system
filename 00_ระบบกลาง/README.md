## ส่วนที่ 3: ตรรกะใหม่

1. ตรวจสิทธิ์ที่เซิร์ฟเวอร์ทุกการกระทำ จากสิทธิ์ปัจจุบัน
2. ชั้นบุคคลชนะชั้นตำแหน่ง ธงสองตัวใช้ได้ทุกหน้า ผู้ใช้หลายสาขาเห็นรวมเฉพาะสาขาที่ผูก
3. เปลี่ยนตำแหน่ง: สิทธิ์ตามตำแหน่งใหม่ทันที ล้างสิทธิ์รายบุคคลทั้งหมด (รวมธง) บันทึกประวัติและแจ้งบนหน้าจอ แต่สาขาที่ผูกไม่ถูกล้าง
4. สิทธิ์เขตแดงต้องใส่เหตุผลก่อนบันทึก และปรากฏในหน้ารวม
5. G04 และ G05 เข้าได้เฉพาะแอดมิน แก้สิทธิ์ตัวเองไม่ได้
6. ทุกการเขียนข้อมูลบันทึกประวัติ (ผู้ทำ ตำแหน่งตอนนั้น ก่อน-หลัง เหตุผล รหัสรายการ+โมดูล) ลิงก์ต้นทางตรวจสิทธิ์ซ้ำตอนกด
7. ลบ = ยกเลิก/ซ่อน งวดล็อกแล้วแก้ย้อนหลังไม่ได้ ปลดล็อกต้องใส่เหตุผล
8. ข้อเสนอที่ผู้ใช้ยังไม่ได้ตกลง: ห้ามถอนสิทธิ์แอดมินคนสุดท้าย

## G01 เข้าสู่ระบบ: สเปคหน้า (ผู้ใช้ตอบครบแล้ว)

### ขั้นตอนของระบบ

กรอกชื่อผู้ใช้และรหัสผ่าน → ตรวจรหัสผ่านเทียบค่าแฮช →
- ผ่าน: บันทึกประวัติ แล้วเข้าหน้าหลัก (G02)
- ไม่ผ่าน: แสดงข้อความเดียว นับครั้งที่ผิด ครบตามค่าตั้งค่าแล้วล็อกบัญชีจนแอดมินรีเซ็ต (G04-4)

### ส่วนประกอบหน้า

| รหัส | รายการ |
|---|---|
| G01-1 ฟอร์ม | ช่องชื่อผู้ใช้, ช่องรหัสผ่าน (ซ่อนตัวอักษร), ปุ่ม "เข้าสู่ระบบ" ปุ่มเดียว |
| G01-2 ข้อความ | ข้อความเดียวทุกกรณี "เข้าสู่ระบบไม่สำเร็จ หากยังเข้าไม่ได้ติดต่อแอดมิน" ไม่แยกว่าชื่อผิด รหัสผิด หรือบัญชีล็อก |
| ไม่มีในหน้า | ลิงก์ลืมรหัสผ่านทางอีเมล (ไม่ผูกอีเมล), คำอธิบาย, โฆษณา |

### กฎและค่าตั้งค่า

| เรื่อง | ค่า | สถานะ |
|---|---|---|
| ชื่อผู้ใช้ | แอดมินตั้งให้ ต้องไม่ซ้ำ (ไม่ใช้รหัสพนักงานตรงๆ) | ตกลงแล้ว |
| ปลดล็อกบัญชี | แอดมินรีเซ็ตเท่านั้น ไม่ปลดเองอัตโนมัติ | ตกลงแล้ว |
| หมดเวลาการใช้งาน | ไม่ได้ใช้งานครบ 2 ชั่วโมงออกจากระบบ (ค่าตั้งค่า แก้ได้) | ตกลงแล้ว |
| จำนวนครั้งที่ผิดก่อนล็อก | 5 ครั้ง (ค่าตั้งค่า แก้ได้) | ข้อเสนอเริ่มต้น ผู้ใช้ไม่ได้ปฏิเสธ |
| ล้างตัวนับครั้งที่ผิด | ล้างเมื่อเข้าสำเร็จ | ข้อเสนอ รอยืนยัน |
| เตือนก่อนหมดเวลา | แจ้งบนหน้าจอก่อนออก 1 นาที | ข้อเสนอ รอยืนยัน |
| รหัสผ่าน | เก็บแบบแฮช แอดมินรีเซ็ตได้แต่ดูไม่ได้ | ตกลงแล้ว |
| ผู้เข้าหน้านี้ | ทุกคน (ไม่ต้องมีสิทธิ์) | ตามชีตหน้าและฟังก์ชัน |

### ประวัติที่บันทึกอัตโนมัติ (G07)

เข้าสำเร็จ, เข้าไม่สำเร็จ (ชื่อผู้ใช้ที่พิมพ์และเวลา ไม่เก็บรหัสผ่านที่พิมพ์), บัญชีถูกล็อก, แอดมินรีเซ็ตรหัสผ่าน ไม่ต้องพิมพ์เหตุผล

### ไม่มีสูตรคำนวณ

G01 ไม่ต้องผ่าน Formula Gate

## G02 หน้าหลัก: สเปคหน้า (ผู้ใช้ตอบครบแล้ว)

### ขั้นตอนของระบบ

หลังเข้าสำเร็จ → อ่านสิทธิ์ปัจจุบัน → แสดงเมนูตามโครงการ → ขอรายการงานค้างจากแต่ละโมดูล → แสดงตัวเลขรวม → กดตัวเลขเห็นรายการรวมใต้ตัวเลข → กดแถวเปิดรายการต้นทาง (ตรวจสิทธิ์ซ้ำตอนกด)

### ส่วนประกอบหน้า

| รหัส | รายการ |
|---|---|
| G02-0 แถบบน (ชิ้นส่วนร่วมทุกหน้า) | ชื่อ, ตำแหน่ง, สาขาที่ผูก, ปุ่มออกจากระบบ กดชื่อเข้า G03 ตัวเล็ก บรรทัดเดียว |
| G02-1 เมนูซ้าย (ชิ้นส่วนร่วมทุกหน้า) | จัดกลุ่มตามโครงการ (G06) ย่อ/ขยายได้ แสดงเฉพาะหน้าที่มีสิทธิ์เข้า โครงการที่ไม่มีหน้าที่เข้าได้จะไม่ขึ้น |
| G02-2 งานค้างของฉัน | ตัวเลขรวมตัวเดียว นับเฉพาะงานที่ตำแหน่งนี้มีสิทธิ์ทำตามสิทธิ์ปัจจุบัน กดแล้วเห็นรายการรวมใต้ตัวเลข ไม่เพิ่มหน้าใหม่ ไม่แจ้งเตือน |
| แถวในรายการรวม | ชื่อรายการ, โมดูลต้นทาง, สถานะ, วันที่ กดแถวเปิดรายการต้นทางในโมดูลนั้น |
| ปุ่ม | "ดู" อย่างเดียว ไม่มีเพิ่ม แก้ ยกเลิก |

### สัญญากับโมดูลอื่น

แต่ละโมดูลส่งงานค้างให้ core 1 แถวต่อ 1 รายการ ประกอบด้วย รหัสรายการ, ชื่อ, สถานะ, วันที่, โมดูล โดยโมดูลกำหนดเองว่า "งานค้าง" ของตัวเองคืออะไร core รวมและเรียงให้

### กฎและสถานะ

| เรื่อง | ค่า | สถานะ |
|---|---|---|
| ตัวเลขงานค้าง | รวมตัวเดียว | ตกลงแล้ว |
| รายการรวม | อยู่ใต้ตัวเลขบน G02 ไม่เพิ่มหน้าใหม่ | ตกลงแล้ว |
| เมนู | ด้านซ้ายทุกหน้า จัดกลุ่มตามโครงการ | ตกลงแล้ว |
| แถบบน | ชื่อ ตำแหน่ง สาขาที่ผูก ออกจากระบบ | ตกลงแล้ว |
| การเรียงรายการรวม | วันที่รอนานสุดขึ้นก่อน | ข้อเสนอ รอยืนยัน |
| มือถือ | เมนูซ้ายพับเป็นปุ่มเมนู | เฟสมือถือ ทำทีหลัง |
| ผู้เข้าหน้านี้ | ทุกคนที่ล็อกอิน เขตเขียว | ตามชีตหน้าและฟังก์ชัน |

G02 ไม่มีสูตรคำนวณ และโครงสร้างโครงการจริงมาจาก G06 (ยังรอตัวอย่างจากผู้ใช้)

## G03 โปรไฟล์: สเปคหน้า (ผู้ใช้ตอบครบแล้ว)

### ขั้นตอนของระบบ

เปิด G03 → แสดงข้อมูลของฉัน (อ่านอย่างเดียว) → กดเปลี่ยนรหัสผ่าน → กรอกรหัสเดิม รหัสใหม่ ยืนยันรหัสใหม่ → ตรวจรหัสเดิม (เทียบค่าแฮช) → ตรวจกฎรหัสใหม่ → บันทึกแบบแฮช → ออกจากระบบเครื่องอื่นของคนนี้ (เครื่องนี้อยู่ต่อ) → บันทึกประวัติ

### ส่วนประกอบหน้า

| รหัส | รายการ |
|---|---|
| G03-1 ข้อมูลของฉัน | ชื่อผู้ใช้, ชื่อ-สกุล, ตำแหน่ง, สาขาที่ผูก, เวลาเข้าล่าสุด, จำนวนครั้งที่ผิดตั้งแต่เข้าครั้งก่อน (อ่านอย่างเดียวทั้งหมด) |
| G03-2 เปลี่ยนรหัสผ่าน | ช่องรหัสเดิม, รหัสใหม่, ยืนยันรหัสใหม่, ปุ่ม "เปลี่ยนรหัสผ่าน" |
| ไม่มีในหน้า | เปลี่ยนชื่อผู้ใช้ ตำแหน่ง สาขา หรืออีเมลเอง |

### กฎและสถานะ

| เรื่อง | ค่า | สถานะ |
|---|---|---|
| กฎรหัสผ่านใหม่ | ยาวอย่างน้อย 8 ตัว (ค่าตั้งค่า แก้ได้) ไม่บังคับชนิดตัวอักษร ต้องไม่ซ้ำรหัสเดิม | ตกลงแล้ว |
| รหัสเริ่มต้นที่แอดมินตั้งหรือรีเซ็ต | แนะนำให้เปลี่ยนแต่ข้ามได้ ใช้ต่อได้ | ตกลงแล้ว |
| ข้อสังเกตของข้อบน | ถ้าผู้ใช้ไม่เปลี่ยน แอดมินที่รู้รหัสเริ่มต้นเข้าในชื่อคนนั้นได้ ประวัติ G07 ยืนยันตัวตนได้ไม่เต็มที่ | บันทึกไว้ ไม่ใช่ข้อห้าม |
| หลังเปลี่ยนรหัสสำเร็จ | ออกจากระบบเฉพาะเครื่องอื่น เครื่องนี้อยู่ต่อ | ตกลงแล้ว |
| แอดมินรีเซ็ตรหัสผ่านให้ผู้ใช้ | ทุกเครื่องของคนนั้นถูกออกจากระบบ | ตกลงแล้ว |
| ประวัติเข้าของตัวเอง | แสดงเวลาเข้าล่าสุดและจำนวนครั้งที่ผิดตั้งแต่เข้าครั้งก่อน | ตกลงแล้ว |
| ข้อความแนะนำเปลี่ยนรหัสผ่านเริ่มต้น | แสดงที่แถบบนจนกว่าจะเปลี่ยน | ข้อเสนอ รอยืนยัน |
| ผู้เข้าหน้านี้ | ทุกคนที่ล็อกอิน เห็นเฉพาะข้อมูลตัวเอง เขตแดง | ตามชีตหน้าและฟังก์ชัน |

### ประวัติที่บันทึกอัตโนมัติ (G07)

เปลี่ยนรหัสผ่านสำเร็จ, เปลี่ยนไม่สำเร็จ (ไม่เก็บรหัสผ่านที่พิมพ์), ออกจากระบบเครื่องอื่นจากการเปลี่ยนรหัสผ่าน

G03 ไม่มีสูตรคำนวณ

## G07 ประวัติใช้งาน: สเปคหน้า (ผู้ใช้ตอบครบแล้ว)

### ขั้นตอนของระบบ

เปิด G07 (บันทึกการเปิดดู) → ตรวจสิทธิ์ดูประวัติ → ตัวกรอง → แสดงแถว → ซ่อนหรือแสดงค่าตามที่ตกลง → กดแถวเปิดรายการต้นทาง (ตรวจสิทธิ์ซ้ำตอนกด) หรือกดส่งออก (ต้องระบุช่วงวันที่ → ไฟล์ Excel → บันทึกการส่งออก)

### ส่วนประกอบหน้า

| รหัส | รายการ |
|---|---|
| G07-1 ตัวกรอง | ผู้ใช้, ช่วงวันที่, โมดูล/โปรแกรม, การกระทำ (มี "ดู" แยกจากการแก้) |
| G07-2 รายการ | ผู้ทำ, ตำแหน่งตอนนั้น, เวลา, การกระทำ, ช่องที่เปลี่ยน (ชื่อช่อง ค่าก่อน ค่าหลัง), เหตุผล, ลิงก์ไปรายการต้นทาง |
| ปุ่ม | ดู, ส่งออก ไม่มีแก้ ลบ ยกเลิก |

### กฎและสถานะ

| เรื่อง | ค่า | สถานะ |
|---|---|---|
| ผู้เข้าหน้านี้ | ตามสิทธิ์ "ดูประวัติ" ขอบเขตสาขา/แผนกตั้งที่ตารางสิทธิ์ตำแหน่ง | ตกลงแล้ว |
| ค่าอ่อนไหวในแถว | แสดงค่าตามจริง รวมต้นทุนและข้อมูลส่วนบุคคล ให้ทุกคนที่มีสิทธิ์ดูประวัติ | ตกลงแล้ว |
| ผลข้างเคียงของข้อบน | สิทธิ์ดูประวัติข้ามธงต้นทุนและธงข้อมูลส่วนบุคคลได้ จึงถือเป็นสิทธิ์เขตแดงใน G05 (ต้องใส่เหตุผล ขึ้นหน้ารวม) | ข้อเสนอ รอยืนยัน |
| การเก็บ | เก็บตลอด ไม่ลบจริง | ตกลงแล้ว |
| ช่วงเริ่มต้นของหน้า | เปิดช่วงล่าสุด 30 วัน ช่วงเก่ากว่านั้นเลือกวันที่เอง | ตกลงหลักการ ตัวเลข 30 วันเป็นข้อเสนอ |
| ค่าก่อน-หลัง | เฉพาะช่องที่เปลี่ยน ไม่เก็บภาพทั้งรายการ ไม่เก็บรหัสผ่านทุกชนิด | ตกลงแล้ว |
| การเปิดดู | บันทึกเฉพาะหน้าที่มีต้นทุน/กำไร ข้อมูลส่วนบุคคล และ G07 หนึ่งแถวต่อการเปิดหนึ่งหน้า ไม่เก็บค่าที่เห็น | ตกลงแล้ว |
| ส่งออก | ตามตัวกรองที่เลือกอยู่ ต้องระบุช่วงวันที่ ไฟล์ Excel (.xlsx) ค่าเหมือนที่เห็นในหน้า บันทึกการส่งออก (ใคร เมื่อไร ช่วงวันที่) | ตกลงแล้ว |
| เพดานแถวต่อไฟล์ส่งออก | ไม่กำหนด | ยังไม่ได้ขอ |
| นำเข้าจากชีต (G11) | บันทึกหนึ่งแถวต่อการดึงหนึ่งครั้ง (เวลา จำนวนแถวใหม่ ผลลัพธ์) ไม่บันทึกทีละแถวธุรกรรม | ข้อเสนอ รอยืนยัน |

G07 ไม่มีสูตรคำนวณ และเป็นเขตแดง

## ร่างโครง G04 G05 G06 G12 (ผู้ใช้จะแก้รายละเอียดทีหลัง)

ทุกข้อในหัวข้อนี้เป็นค่าเริ่มต้นที่ผมเสนอ ติดป้ายว่า "ตกลงแล้ว" เมื่อมาจากคำตอบของผู้ใช้ และ "ข้อเสนอ" เมื่อเป็นค่าที่ผมเสนอเอง

### G04 จัดการผู้ใช้

ขั้นตอนของระบบ: เปิด G04 → ค้นหา/กรองผู้ใช้ → เลือกหรือสร้าง → กรอกข้อมูล → บันทึก (บันทึกประวัติ) / รีเซ็ตรหัสผ่าน / ปิดการใช้งาน

| รหัส | รายการ | สถานะ |
|---|---|---|
| G04-1 รายการ | ค้นหาและกรองตามสาขา ตำแหน่ง สถานะ | ตกลงแล้ว |
| G04-2 ข้อมูลผู้ใช้ | ชื่อผู้ใช้ (แอดมินตั้ง ไม่ซ้ำ), ชื่อ-สกุล, ตำแหน่ง 1 ตัว, สาขาที่ผูก (หลายสาขา), โครงการ, สถานะใช้งาน/ปิด | ตกลงแล้ว |
| G04-3 สิทธิ์รายบุคคล | ธง 2 ตัว (เห็นต้นทุน/กำไร, เห็นข้อมูลส่วนบุคคล) ล้างเมื่อเปลี่ยนตำแหน่ง สาขาที่ผูกไม่ล้าง | ตกลงแล้ว |
| G04-4 รีเซ็ตรหัสผ่าน | ดูรหัสเดิมไม่ได้ ออกจากระบบทุกเครื่องของคนนั้น ปลดล็อกบัญชีด้วย | ตกลงแล้ว |
| รหัสเริ่มต้น | ระบบสุ่มให้และแสดงครั้งเดียวตอนสร้างหรือรีเซ็ต | ข้อเสนอ |
| ปิดการใช้งาน | ซ่อน ไม่ลบ ออกจากระบบทันที ประวัติยังอยู่ ไม่ใช้ชื่อผู้ใช้ซ้ำ | ซ่อน ไม่ลบ ตกลงแล้ว ที่เหลือข้อเสนอ |
| ปุ่ม | เพิ่ม, แก้ไข, ปิดใช้งาน, รีเซ็ตรหัสผ่าน, ตั้งสิทธิ์รายบุคคล | ตามชีต |

### G05 ตำแหน่งและสิทธิ์

ขั้นตอนของระบบ: เปิด G05 → เลือกตำแหน่ง → แสดงตารางหน้า × ปุ่ม → ติ๊กสิทธิ์ → ถ้าแตะสิทธิ์เขตแดงให้ใส่เหตุผล → บันทึกมีผลทันที → บันทึกประวัติ และขึ้นหน้ารวม

| รหัส | รายการ | สถานะ |
|---|---|---|
| G05-1 รายการตำแหน่ง | รหัสตำแหน่งและชื่อจากรายการเดิม 51 ฉบับ เพิ่มหรือยกเลิกตำแหน่งได้ | ตกลงแล้ว (ยกเลิกตำแหน่งที่ยังมีคนอยู่ไม่ได้ = ข้อเสนอ) |
| G05-2 ตารางสิทธิ์ | คอลัมน์คือปุ่มของแต่ละหน้า ระบบสร้างรายการปุ่มเอง ปุ่มสามัญจัดเป็นกลุ่ม และขอบเขตข้อมูลต่อหน้า (ทุกสาขา / สาขาที่ผูก / แผนกตัวเอง) | ตกลงแล้ว |
| G05-3 ธงของตำแหน่ง | เห็นต้นทุน/กำไร, เห็นข้อมูลส่วนบุคคล | ตกลงแล้ว |
| G05-4 เหตุผล | ต้องใส่เมื่อแตะสิทธิ์เขตแดง | ตกลงแล้ว |
| G05-5 หน้ารวม | สิทธิ์เขตแดงที่ให้ไว้ทั้งหมด เป็นแท็บใน G05 | หน้ารวมตกลงแล้ว แท็บเป็นข้อเสนอ |
| สิทธิ์เขตแดง | เห็นต้นทุน/กำไร, เห็นข้อมูลส่วนบุคคล, ดูประวัติ (G07), ปลดล็อกงวด, KPI ที่ผูกค่าตอบแทน | เขตแดงตกลงแล้ว ดูประวัติและปลดล็อกงวดเป็นข้อเสนอ |
| วิธีตั้ง | ตั้งทีละตำแหน่ง คัดลอกสิทธิ์จากตำแหน่งอื่นได้ และมีมุมมองกลับด้านอ่านอย่างเดียว (เลือกหน้า ดูว่าตำแหน่งไหนเข้าได้) | ข้อเสนอ |
| ตำแหน่งใหม่ | เริ่มโดยไม่มีสิทธิ์ใดเลย | ข้อเสนอ |
| มีผล | ทันทีที่บันทึก | ข้อเสนอ |
| ข้อห้าม | แก้สิทธิ์ตัวเองไม่ได้ (ตกลงแล้ว) ห้ามถอนแอดมินคนสุดท้าย (ข้อเสนอ) | |

### G06 โครงการ/กลุ่มเอกสาร

ขั้นตอนของระบบ: เปิด G06 → สร้างหรือแก้โครงการ (ชื่อ + หน้าในโครงการ) → สร้างหรือแก้กลุ่มเอกสาร (ชื่อ + ตำแหน่งหรือบุคคลที่เห็น) → บันทึก (บันทึกประวัติ)

| รหัส | รายการ | สถานะ |
|---|---|---|
| G06-1 โครงการ | ชื่อ, รายการหน้าในโครงการ ใช้จัดกลุ่มเมนูใน G02 | ตกลงหลักการ |
| G06-2 กลุ่มเอกสาร | ชื่อ, ตำแหน่ง/บุคคลที่เห็นเอกสารกลุ่มนั้น | ตกลงหลักการ |
| สิทธิ์ | "กำหนดกลุ่มเอกสาร" เป็นปุ่มแยกในตารางสิทธิ์ (G05) | ตามชีต |
| ตัวอย่างจริง | รอผู้ใช้ให้ตัวอย่างโครงการและกลุ่มเอกสารจริง ตอนนี้ทำเฉพาะโครงสร้างว่าง | รอข้อมูล |

### G12 งวด

ขั้นตอนของระบบ: เปิด G12 → เลือกงวดรายเดือน → ปิดงวด (ล็อกการแก้ย้อนหลังของหน้าที่ผูกกับวันที่) / ปลดล็อก (ต้องใส่เหตุผล) → บันทึกประวัติ

| รหัส | รายการ | สถานะ |
|---|---|---|
| G12-1 รายการงวด | งวดรายเดือน สถานะเปิดหรือล็อก | ตกลงแล้ว |
| G12-2 ปิดงวด/ปลดล็อก | ปลดล็อกต้องใส่เหตุผลและบันทึกประวัติ ปุ่มปิดงวดและปลดล็อกตั้งที่ตารางสิทธิ์ | ตกลงแล้ว |
| งวดนับตาม | เดือนของวันที่จ่ายจริง (กำหนดไว้แล้วสำหรับค่าใช้จ่าย) โมดูลอื่นกำหนดวันที่ของตัวเอง | ตกลงแล้วสำหรับค่าใช้จ่าย |
| ปิดได้เมื่อ | เดือนนั้นสิ้นสุดแล้วเท่านั้น | ข้อเสนอ |

## ที่ยังค้างก่อนลงรายละเอียดหน้า

- ข้อเสนอของ G04 G05 G06 G12 ในหัวข้อ "ร่างโครง" ทั้งหมดรอผู้ใช้แก้
- ข้อเสนอของ G07 ที่รอยืนยัน: ถือสิทธิ์ดูประวัติเป็นสิทธิ์เขตแดงใน G05, ช่วงเริ่มต้น 30 วัน, บันทึกการนำเข้าเป็นหนึ่งแถวต่อครั้ง
- ข้อเสนอเรียงรายการงานค้างของ G02 (วันที่รอนานสุดขึ้นก่อน) รอยืนยัน
- รหัสผ่านเริ่มต้นที่แอดมินตั้ง (พิมพ์เองหรือระบบสุ่มให้แสดงครั้งเดียว) และธง "แนะนำให้เปลี่ยน" ของบัญชีใหม่: ไปตัดสินที่ G04
- ข้อเสนอของ G03 ที่รอยืนยัน (ข้อความแนะนำเปลี่ยนรหัสผ่านที่แถบบน)
- ข้อเสนอ 2 ข้อของ G01 ที่รอยืนยัน (ล้างตัวนับเมื่อเข้าสำเร็จ, เตือนก่อนหมดเวลา)
- รายการสิทธิ์ทั้งหมดของ HERO (ผู้ใช้จะลิสต์ให้)
- ตัวอย่างกลุ่มโครงการและกลุ่มเอกสารจริง (G06)
- ใครปลดล็อกงวดได้ (ตกลงไว้ในหมวด H ว่าผู้ใช้คนเดียว ต้องยืนยันตอนทำ G12)
- G05-5 เป็นแท็บใน G05 หรือหน้าใหม่
- ข้อเสนอห้ามถอนแอดมินคนสุดท้าย
