# ระบบขายสินค้าโปรโมชั่น (ระบบเดิมที่มีอยู่)

เฟส (ข้อเสนอ v0, รอยืนยัน): 3
สถานะ: ร่างโครง v0 ผู้ใช้จะแก้ทีหลัง ยังไม่ได้ grill **มีระบบเดิมใช้งานอยู่** ต้องตรวจก่อนว่าหน้าไหนมีแล้ว ห้ามสร้างซ้ำ สิทธิ์ทุกปุ่มตั้งที่ตารางสิทธิ์ตำแหน่ง (`00_ระบบกลาง`)

## ขั้นตอนของระบบ

นิยามแพ็กโปรโมชั่น (สินค้า ราคา ช่วงเวลา) → ลูกค้าที่เข้าร่วมเลือกแพ็ก → ออเดอร์ที่ลูกค้าเลือก → ส่งออเดอร์เข้าบิลขายและตัดสต๊อกเป็นรายสินค้าในแพ็ก แท็กช่องทางสำหรับคอม → รายงานโปรโมชั่น (ยอดตามแพ็ก/ลูกค้า)

## หน้าและฟังก์ชัน

| รหัส | หน้า | ฟังก์ชันหลัก | เขต |
|---|---|---|---|
| PM-01 | นิยามแพ็กโปรโมชั่น | สินค้าในแพ็ก ราคา ช่วงเวลา | แดง (ราคา/โปร) |
| PM-02 | ลูกค้าที่เข้าร่วม | รายชื่อลูกค้าที่ร่วมโปร | แดง (ข้อมูลส่วนบุคคล) |
| PM-03 | ออเดอร์ที่ลูกค้าเลือก | ดูแพ็กที่แต่ละลูกค้าเลือก | เหลือง |
| PM-04 | ส่งเข้าบิลและตัดสต๊อก | ส่งออเดอร์เข้าบิลขาย ตัดสต๊อกรายสินค้า แท็กช่องทาง | แดง |
| PM-05 | รายงานโปรโมชั่น | ยอดตามแพ็ก/ลูกค้า | เหลือง |

## ค่าเริ่มต้นที่เสนอ

| เรื่อง | ค่า | สถานะ |
|---|---|---|
| แนวทาง | ตรวจระบบเดิมก่อน ถ้ามีหน้าอยู่แล้วให้ครอบหรือเชื่อมกับ core (สิทธิ์ ประวัติ งวด) ไม่สร้างหน้าซ้ำ | ตามชีต |
| ใครแก้ได้ | ตั้งที่ตารางสิทธิ์ตำแหน่ง | ตกลงแล้ว |

## ข้อมูลที่ต้องการจากผู้ใช้

ระบบเดิมมีหน้าและฟังก์ชันอะไรแล้ว (ที่เก็บ ใครดูแล) · ใครเป็นต้นฉบับของบิลและสต๊อกที่ถูกตัด (HERO หรือระบบใหม่) เพราะระบบใหม่อ่านจาก HERO อย่างเดียว

## สูตรที่รอ Formula Gate

ไม่มีในรายการหน้า ถ้าระบบเดิมมีการคำนวณราคาแพ็กต้องตรวจก่อน

`02_คอมมิชชั่น` (แท็กช่องทาง) · `13_คลัง` (ตัดสต๊อก) · `00_ระบบกลาง` G08, G09
